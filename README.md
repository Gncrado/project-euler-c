# Project Euler Solutions in C

This repository is my personal collection of solutions to problems from [Project Euler](httpsprojecteuler.net).

I created this repository to improve my problem-solving, algorithmic thinking, and C programming skills while keeping a record of my progress.

The solutions in this repository are not necessarily the most efficient, optimal, or definitive approaches. They represent the algorithms I developed with my current knowledge that produced the correct results.

As I continue learning, I may revisit earlier problems, improve their algorithms, and refactor their code.

## Repository Structure

Each problem is stored in its own directory

```text
project-euler-c
├── problem-001
├── problem-002
├── problem-003
└── ...
```

## Disclaimer

Project Euler encourages participants to solve problems independently. This repository is intended primarily as a personal learning archive. If you are currently working on these problems, I recommend attempting them yourself before reviewing any solution.
